==🔵**Types of storage in Java**==

==🟠*Field Storage :*==
- *Field storage are the instance, static and local fields of java program.*
- *It means instance, static and local variables are the field storage.*
- *Field storage is a temporary storage.*

==🟠*Object Storage :*==
- *It is an storage for an object created in the java program.*
- *It is stored in the heap memory.*
- *Object Storage is also a temporary storage.*

==🟠*Files Storage :*==
- *Files are used to store the data.*
- *It is permanent storage but here the problem is with data inconsistency, data integrity, data redundency and data security.*

==🟠*Database Storage :*==
- *It solves most of the problem of file storage.*
- *Here the data is stored in organized way and data is consistent with integrity and security.*

==🔵**PPPPP**==
- *Persistent ➜ A process to store data.*
- *Persistent Data ➜ The data being stored in the database.*
- *Persistent Store ➜ The place where the data is being stored.*
- *Persistent Process ➜ The operation like `CREATE`, `READ`, `UPDATE` and `DELETE` are persistent process.*
- *Persistent Logic ➜ `JDBC` which performs the db operation.*
