==🔵**The 7 components of JDBC :**==
- **JDBC API** ➜ *Provides interfaces and classes for connecting and interacting with the database.*
- **JDBC Driver Manager Class** ➜ *It is a class which manages the database drivers and establishes the connection.*
- **JDBC Driver** ➜ *It translates the `JDBC` calls into a database specific call. There are 4 `JDBC` drivers.*
- **Connection** ➜ *It is an interface which represents a connection to a database.*
- **Statements** ➜ *It is used to execute SQL queries. Statements are of 3 types.*
- **Result Set Interface** ➜ *It is an interface represents the result set of a query.*
- **SQL Exception** ➜ *This class handles the errors and exceptions in connecting the database.*

==🔵**JDBC Driver :**==
*Definition : A driver acts as a bridge between a java progam and the database. The dirver converts java into database specific calls.*
*We are having 4 types of JDBC drivers :*

==🟠*JDBC - ODBC Bridge Driver*==
- *ClassName : `sun.jdbc.odbc.JdbcOdbcDriver`*
- *It is developed by sun microsystems.*
- *It translates JDBC calls into ODBC calls.*
- *It acts as bridge between Java Program and Database.*

==🟠*NATIVE API Driver*==
- *ClassName : `oracle.jdbc.driver.OracleDriver`*
- *It is a developed database vendors. Ex : Oracle, Sysbase etc.*
- *It translates JDBC calls into Native Api calls.*
- *It is a bridge between JDBC and the database.*➜

==🟠*NETWORK PROTOCOL Driver*==
- *ClassName : `com.sysbase.jdbc3.jdbc.SysDriver`*
```
JDBC Code ⇄ Network Protocol Driver ⇄ Middleware ⇄ Database
```

==🟠*THIN Driver*==
- *ClassName : `oracle.jdbc.OracleDriver`*
- *Written entirely in java and communicate directly.*
```
JDBC Code ⇄ Thin Driver ⇄ Databse
```
