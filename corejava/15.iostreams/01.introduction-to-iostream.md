==🔵**What is Data? Where does a program get data from?**==
*We get data from various sources like :*
- *Keyboard*
- *File*
- *Database*
- *Network*
- *Scanner*

==*Example*==
```java
int age = 25;
```
Here *25* is the data.

==🔵**What is Input?**==
*Input means taking data into the program. Sources for input are :*
- *Keyboard ➜ Program*
- *File ➜ Program*
- *Network ➜ Program*
- *Database ➜ Program*

==*Example*==
```java
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
```
*Flow of the input*
➜ *User enters :* `25`
➜ *The program receives the data 25.*
==*This is the input data.*==

==🔵**What is Output?**==
*Output means sending data from program to somewhere else. Here are some output examples are :*
- *Program ➜ Monitor*
- *Program ➜ File*
- *Program ➜ Printer*

==*Example*==
```java
System.out.println(age);
```
`OUTPUT : 25`

==🔵**What is a File? After the termination of program what happens to the variables?**==

==*Example*==
```java
int salary = 25000;
```
==*After the program terminates*==
- *Salary variable disappears.*
- *Data is lost. This is called temporary storage.*
- *To store the data permanently we use files.*

==*Examples:*==
- `employee.txt`
- `student.txt`
- `photo.jpg`
- `movie.mp4`

==🟠*A file stores data permanently inside storage devices.*==

==🔵**What is a Stream?**==
- *A stream is a channel through which data travels from **source** to **destination** *
- *Stream is a pipeline which process the data elements one by one rather than storing them.*
- *It was introduced in Java 8.*

==*This is how the data flows through the stream :*==
- *File ➜ Stream*
- *Stream ➜ Java Program*

==🔵**Why Streams?**==
*Java can not directly talk to a file. Java needs a medium to handle files that is ==Stream==.*
**Stream data flows like :**
- *File ➜ Stream ➜ Program*
- *Program ➜ Stream ➜ File*

==🟢*Therefore stream acts like a bridge between file and java program.*==
